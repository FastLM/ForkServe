Agentic LLM workloads repeatedly fork a committed context into $k$ candidate continuations and retain at most one.
Under prefill--decode (PD) disaggregation, each candidate is prefilled and its KV cache transferred before any decode-time pruner can reject it, so pruning decisions arrive after the cost they should avoid.
We propose \emph{PD pruning disaggregation}, which separates where a pruning decision is made, where it is executed, and how pruned KV state is managed.
\sys assigns each candidate one of four actions (\Hit, \Admit, \Probe, \Reject) before any kernel runs, using model-free scores and KV residency on both instances; extends uncertain candidates only if a short decoded probe passes a separate threshold; and uses a copy-on-write context tree that transfers only decoder-missing pages and retains only the committed path.
On Qwen3-8B, admission in front of ESC, Speculative Rejection, and DPTS reduces computed prefill by $23\%$ while committed-answer accuracy changes by at most two of $16$ problems; on MATH-500 the probe restores the coverage lost by blanket rejection ($20/32$ vs.\ $13/32$) at $0.69\times$ the wall-clock of the full fan-out; on GSM8K with Qwen3-14B the retained path needs $0.72\times$ the peak KV of prefix caching at equal accuracy.
