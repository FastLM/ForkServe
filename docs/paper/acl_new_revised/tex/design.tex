\section{System Details}
\label{sec:design-full}

\sys sits between the agent harness and the LLM engine (\Cref{fig:system}).
The harness exposes branch structure, the controller decides and binds, and the engine executes prefill, transfer, and decode.

\subsection{Copy-on-Write Context Tree}
\label{sec:state}

\begin{definition}[Context tree]
A session is a rooted tree $T=(V,E)$.
Node $u$ stores a token sequence $x_u$ with $x_{\pi(u)}\preceq x_u$, a residual $\delta_u=x_u[|x_{\pi(u)}|{:}]$, a mode in $\{\textsc{Spec},\textsc{Commit},\textsc{Idle},\textsc{Dead}\}$, a generation $g_u$, and a page table $\sigma_u=(\mathrm{parent},\mathrm{alias\_len},\mathrm{pages}_u)$.
\end{definition}

The tree maintains four invariants: (i)~prefix closure; (ii)~at most one committed child per node outside a join; (iii)~speculative nodes are never sampled from; (iv)~the reference count of a page equals the number of non-dead nodes that map it.
\texttt{fork}$(u,\cdot)$ writes two words, $(\mathrm{parent}\leftarrow\sigma_u,\ \mathrm{alias\_len}\leftarrow|x_u|)$, and increments the reference counts of the aliased pages; a write to a shared or read-only page copies only its valid rows.
A multi-level fan-out is a sequence of such forks (\Cref{fig:tree}); abort frees residual pages only, and a subtree without live descendants is reclaimed up to the nearest ancestor with a live child.
Commit publishes the full pages of $x_\star$ to the prefix index so that later requests can hit them.
Eviction is node-granular: speculative leaves first, then idle committed leaves, then the spine~\cite{continuum,mori}.

\subsection{Speculative Prefill of Known Suffixes}
\label{sec:speculate}
A candidate of parent $u$ is a pair $(x^{\mathrm{k}},\hat{x}^{\mathrm{o}})$ of a known suffix and a predicted observation, with admission probability $p$ and expected prefix-hit rate $q$.
Known suffixes ($p{=}q{=}1$) are scheduled before predicted observations ($q{<}1$), subject to the idle time $\Idle(u)$, the available KV capacity, and a branch cap.
Unlike speculative decoding~\cite{speculative,medusa}, the object prefilled is a future \emph{prompt} prefix rather than draft output tokens.
On commit, the pages covered by $\mathrm{LCP}(x,x_{v^\star})$ become committed, the unmatched tail is prefilled, every sibling is aborted, and jobs tagged with a stale generation are dropped in $O(1)$.

\subsection{Admission Details}
\label{sec:app-detail}

\paragraph{Scorers.}
$\mathrm{Score}_{\mathrm{pre}}$ assigns $0.02$ to a residual containing a substring of $8$--$40$ characters repeated at least four times, $0.22$ to a residual containing malformed mathematical tokens (e.g., runs of asterisks or \texttt{nan}), and otherwise a weighted combination of alphanumeric fraction and character diversity, which is close to $1$ for natural prose.
$\mathrm{Score}_{\mathrm{dec}}$ applies the same repetition and malformation tests to the generated prefix ($0.04$ and $0.16$), assigns $0.92$ once a finished answer marker (\texttt{\#\#\#\#} followed by a number, or \texttt{\textbackslash boxed\{}) appears, and otherwise uses a weighted combination that also rewards digits and operators.
Both scorers run on the CPU and do not share parameters.

\paragraph{Ordering of the action.}
\eqref{eq:action} reads decode-side residency first, because a residual already resident on $\Din$ costs neither prefill nor transfer.
It then protects index $0$, so the top-ranked continuation is always served.
Only then does it consult the score.
A page resident only on $\Pin$ reduces $W_i$ but not $X_i$; the residual is admitted with $W_i{=}\ell_i-m_i^{\Pin}$ and $X_i{=}\ell_i-m_i^{\Din}$.
\Cref{fig:radix} illustrates the four actions on one radix tree, and \Cref{fig:app} places them on the request path.

\subsection{Critical-Path Placement}
\label{sec:schedule}
After abort the live occupancy is $M_{\mathrm{spine}}$, so a pool of $M_{\mathrm{pool}}$ bytes holds
\begin{equation}
\label{eq:slots}
C=\bigl\lfloor M_{\mathrm{pool}}/M\bigr\rfloor
\end{equation}
sessions, with $M{=}M_{\mathrm{spine}}$ for \sys and $M{=}M_{\mathrm{APC}}$ while a prefix cache retains aborted residuals.
On tick $t$ the chunk budget~\cite{sarathi} is split by the committed rate $\underline{s}_r$~\cite{jitserve},
\begin{align}
B^{\mathrm{c}}_t &= \min\Bigl(B_t,\; \sum_{r\in R^{\mathrm{c}}_t}\max(\underline{s}_r\Delta,\;1)\Bigr), \label{eq:bc}\\
B^{\mathrm{s}}_t &= B_t-B^{\mathrm{c}}_t. \label{eq:bs}
\end{align}
$B^{\mathrm{c}}_t$ decodes committed spines; $B^{\mathrm{s}}_t$ prefills admitted residuals or known suffixes ($p{=}1$) when $\Pref(|w|)\le\Idle(u)$.
Speculatively prefilled tokens are never sampled from.
