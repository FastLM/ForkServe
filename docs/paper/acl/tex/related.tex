\section{Related Work}
\label{sec:related}

\paragraph{Path pruning during search.}
Chain-of-thought prompting showed the value of intermediate steps~\citep{cot}.
Tree-of-Thoughts, self-consistency, and ReAct expand several reasoning paths and then retain one trajectory~\citep{tot,selfconsistency,react}.
A later line prunes those paths once they have been written.
EquivPruner trains a lightweight detector of mathematical statement equivalence and keeps one representative from each equivalent set, cutting token use during search~\citep{equivpruner}.
STOP reads the KV cache of a generated prefix through a learned token and resumes only the top-ranked paths, which is a launch--check--resume schedule over prefixes that already exist~\citep{stop}.
Both methods shorten exploration after the candidate text is resident.
An earlier threshold inside that family reduces decode and leaves the prefill of every sibling in place.
\sys reads the residual before those tokens exist, inserts KV only for the admitted set, and leaves the host cut in place for residuals that remain.
EquivPruner and STOP can still rank that admitted set: they decide which surviving residual to continue, which is the role of $s^{\mathrm{dec}}$ and of the host.

\paragraph{Decode-time early stopping.}
ESC closes the sample once a window of answers agrees~\citep{esc}; speculative rejection spends a partial-reward horizon and then drops the lower quantile~\citep{specrej}; DPTS grows a tree in mini-steps and stops a child whose confidence is low~\citep{dpts}.
Section~\ref{sec:background} records the text each score reads.
The decode score in \sys is a probe of a sibling residual, whereas speculative decoding checks a draft continuation of the same sequence~\citep{speculative}.

\paragraph{LLM serving.}
Orca batches at iteration granularity~\citep{orca}.
PagedAttention and automatic prefix caching address KV as blocks and reuse a block after its hash is stored~\citep{vllm}; SGLang's radix cache implements the same contract for program-structured calls~\citep{sglang}.
DistServe and Splitwise place prefill and decode on separate instances and ship KV across the cut~\citep{distserve,splitwise}.
These designs remove recomputation of a stored prefix and isolate time-to-first-token from inter-token latency.
The first fan-out of a new trunk has nothing stored, and the connector forwards every page the prefiller computed, including residuals the harness will abort.
Training-time methods that modify the model, and test-time workflows that add extra model calls per response, require a larger budget than a pair of string scores.
\sys is the admission step in front of that kernel and that transfer.
It is complementary to the existing serving stack and uses the page allocator those systems already provide.
