\section{Background and Model}
\label{sec:problem}

\subsection{Prefill, Decode, and Idle}
Autoregressive inference has two mechanically different phases~\cite{orca,distserve,splitwise}.
\emph{Prefill} consumes the prompt in parallel and is compute-bound; \emph{decode} emits one token (or a small chunk) per step and is memory-bandwidth bound.
PagedAttention~\cite{vllm} stores KV in non-contiguous pages; RadixAttention~\cite{sglang} indexes pages by token prefix so concurrent requests that share a system prompt hit a common trunk.
Two consequences matter for agents.
First, next-turn \ttft{} is the prefill of tokens that miss the cache, plus queuing.
Second, a memory-bound decode batch rarely saturates the tensor cores that a concurrent chunked prefill could use~\cite{sarathi}.
Agent serving adds a third fact: the prompt of turn $i{+}1$ is a \emph{delta} on turn $i$, applied after a tool pause of highly variable length~\cite{continuum,mori}.

\subsection{A Branching Step}
\label{sec:model}
We treat one agentic step as a rooted prefix tree, not as $k$ independent completions.

\begin{definition}[Branching step]
A parent node $u$ holds a committed trunk $x_u$ of length $L$.
A harness-declared fan-out produces $k$ children with residuals $\rho_i$ of length $\ell_i$, $i\in\{1,\ldots,k\}$.
After a winner $\star$ is bound, only the spine $x_\star=x_u\Vert\rho_\star$ of length $L+\ell_\star$ remains live.
\end{definition}

\Cref{tab:notation} is the symbol set used in the rest of the paper.
Let $b$ be bytes of KV per token (all layers, one sequence) and $P$ the page size in tokens.
Three occupancies follow immediately:
\begin{align}
M_{\mathrm{clone}} &= b\bigl(kL+\textstyle\sum_i\ell_i\bigr), \label{eq:mem}\\
M_{\mathrm{CoW}} &= b\bigl(L+\textstyle\sum_i\ell_i\bigr), \nonumber\\
M_{\mathrm{spine}} &= b\bigl(L+\ell_\star\bigr). \nonumber
\end{align}
The first-fan-out work of a scheme is the number of tokens sent to a GPU prefill kernel before the winner is known; the transfer span is the number of tokens a P/D connector ships.

\paragraph{Why APC misses the first fan-out.}
APC indexes a \emph{full} block by $h=\mathrm{hash}(\mathrm{parent},\;\mathrm{tokens},\;\mathrm{extra})$ \emph{after} those tokens exist~\cite{vllm}.
A same-batch ToT expansion looks up $k$ children before any child has published a hash, so the walk misses and the engine clones $k$ trunks:
$\Work_{\mathrm{APC}}=kL+\sum_i\ell_i$.
A later replay of the committed winner is a full hash hit ($\Work{=}0$).
Hash-only prefill therefore helps the second session, not the first expand.

\paragraph{Why stock P/D does not raise tokens/s.}
DistServe/Splitwise isolate \ttft{} from ITL by running prefill and decode on different instances and moving KV through a connector ($\texttt{insert}$ non-blocking, $\texttt{drop\_select}$ blocking)~\cite{distserve,splitwise}.
The stock connector ships every page the prefiller computed,
\begin{equation}
\label{eq:xfer-stock}
\Xfer_{\mathrm{PD}}=kL+\textstyle\sum_i\ell_i,
\end{equation}
so first-fan-out transfer equals first-fan-out work.
P/D is a placement, not a branch filter.

\paragraph{Four operators that generate the tree.}
Tool intercept~\cite{react,toolformer} idles the engine while the environment runs; a known suffix is available immediately and an observation residual arrives later.
Fan-out/join~\cite{autogen,metagpt} launches $k$ children that share $x_u$ and differ in short role residuals.
Search~\cite{tot,hive} expands $b$ siblings, scores them, and recurses on a shared spine.
Context transformation~\cite{smoothagent} forks a summarized child while the original spine stays abortable.
In all four cases the next call is drawn from a discrete set $\Br(u)$; existing engines observe only the child that is eventually issued.

\begin{insight}[Prune before prefill]
\label{ins:prune}
APC reuses a trunk only after a hash hit; stock P/D ships whatever was computed.
The missing verb is a per-residual decision $(\Work_i,\Xfer_i,a_i)$ issued \emph{before} a GPU kernel and \emph{before} \texttt{insert}.
\end{insight}

\begin{insight}[Fork, don't clone]
\label{ins:fork}
On fan-out the trunk is typically several times the per-child residual.
Materializing $k$ independent KV copies wastes $\Theta(k)$ HBM for tensors attention will read as identical.
A location-addressed alias at \texttt{fork} makes a miss residual-only.
\end{insight}
